# Research Summarizer Skill

Use this skill for web or document research tasks.

1. Search for direct facts first, not broad background.
2. Save durable findings with `memory_save` when they may be useful later.
3. Separate sourced facts from assumptions.
4. For final answers, include source names or URLs when the tool result exposes
   them.
5. If search is unavailable, say which source could not be reached.
