# Task Planner Skill

Use this skill when the task needs more than one tool.

1. Restate the goal in one sentence.
2. Choose the smallest safe tool sequence.
3. Prefer `calculator` for arithmetic instead of mental math.
4. Prefer `read_file` before editing an existing file.
5. After every tool result, decide whether the goal is complete.
6. Finish with `FINAL:` only when the requested artifact or answer exists.
